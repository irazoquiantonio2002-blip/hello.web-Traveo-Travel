# Traveor Travel — sitio web

Landing page de una sola página para **Traveor Travel**, agencia de viajes en
Pachuca, Hidalgo. HTML + CSS + JS sin frameworks ni build.

## Estructura

```
index.html      Marcado de todas las secciones
styles.css      Sistema de diseño (tipografía Fraunces + Plus Jakarta Sans, paleta de marca)
script.js       Loader, nav, menú móvil, reveals, parallax, typewriter, carrusel de videos
videos/         Videos de "Experiencias destacadas" (ver videos/README.md)
IMAGENES.md     Registro de imágenes y pendientes de contenido
```

## Secciones (menú)

`Inicio` · `Viaja con Traveor` · `Destinos` · `Nosotros` · `Contacto`
Más un botón fijo de WhatsApp.

## Recorrido de la Home

Hero → Confianza (RNT / certificaciones) → Beneficios → **Pon tu cotización a prueba** →
**Experiencias destacadas (videos)** → Servicios + Cómo trabajamos → Destinos →
Nosotros (historia · fundadoras · misión · visión · valores · propuesta de valor · respaldo) →
Contacto → WhatsApp.

## Ver en local

Abrir `index.html` en el navegador, o servir la carpeta:

```
npx serve .
```

## Pendientes de contenido

Ver **`IMAGENES.md`**: foto real de las fundadoras, los 5 videos y los enlaces
específicos de paquetes de Viaje.ly.
